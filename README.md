# Hridoy Roy — Portfolio

Simple, professional personal portfolio for **Hridoy Roy**, Software Engineer.

Built with **Angular 19** from his CV (ASP.NET Core / Angular enterprise experience).

## Run locally

```bash
npm install
npm start -- --host 0.0.0.0 --port 43123
```

Open [http://127.0.0.1:43123](http://127.0.0.1:43123).

## Sections

- Landing / Hero (with portrait)
- About
- Experience
- Projects
- Skills
- Education & Training
- Achievements
- Contact
